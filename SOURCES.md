# Learning sources

This vault is structured around the user-provided learning outline **“Every AWS Service You’ll EVER Need”**: seven buckets, day-one setup, hands-on labs, seven portfolio projects, milestone phases, cost management and communities. The source outline contained many blank link slots; this initial vault fills selected slots with official AWS documentation and preserves the source's practical learning order.
